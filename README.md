# ShjContact

دليل الاتصال والبروتوكول — الشارقة

- آخر مراجعة للهواتف: 8 أكتوبر 2026.
- الواجهة الرئيسية للنسخة العامة: `index.html`.
- نقطة دخول إضافية: `Standalone.html`.
- `data.js` يحمّل قاعدة البيانات المضغوطة من مجلد `data/` قبل تشغيل `app.js`.
- خط Alexandria في النسخة العامة يُحمّل عبر Google Fonts، مع Arial كخط بديل.

> النسخة المنشورة على GitHub مهيأة للاستخدام عبر الويب. حزمة الاستخدام المحلي دون اتصال تبقى نسخة منفصلة ولا تُنشر معها ملفات الخط المحلية.
